==============================================================
MEDIA WEB INTERAKTIF: ADAB WUDHU MULTI-SENSORY (MAZHAB SYAFI'I)
==============================================================

1. CARA MEMBUKA DI LAPTOP (OFFLINE / PROYEKTOR KELAS):
   - Buka folder ini (web-adab-wudhu).
   - Klik dua kali (double-click) file: index.html
   - Media akan langsung terbuka di Google Chrome / Microsoft Edge.
   - Klik tombol "Proyektor" di pojok kanan atas untuk tampilan layar penuh.

2. CARA MENAMBAHKAN AUDIO USTADZ ABDUL SOMAD / SUARA GURU:
   - Buka menu "Studio Guru" di bilah navigasi atas.
   - Klik "Unggah MP3" pada tiap segmen (1 s.d. 8) atau klik "Rekam Suara".
   - File audio otomatis tersimpan di browser Anda (IndexedDB) sehingga tetap ada saat dibuka kembali.

3. CARA MEMPUBLIKASIKAN KE INTERNET (GRATIS & TANPA INSTALL):
   - Buka https://app.netlify.com/drop di browser.
   - Tarik (drag & drop) seluruh folder "web-adab-wudhu" ke halaman tersebut.
   - Dalam beberapa detik Anda akan mendapatkan tautan web (https://...) yang bisa dibagikan ke siswa, dosen pembimbing, atau validator pakar.
